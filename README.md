# Family English Daily 和孩子一起说英语

以双语育儿为主线的英语学习网页。给家长读的进阶文本与适合对孩子说的简短用语分开呈现，帮助把学习带进真实生活。

## 包含什么

- 首月20篇原创英文短文、中文释义、重点词块、亲子用语和30天安排。
- 可扩展的月份课程库和12个月学习路线。
- 逐句精听、语速与循环控制、遮文练习、跟读录音和听写核对。
- 表达卡、间隔复习、学习笔记、打卡和JSON备份。
- 英语教练：按意思重组自然美式英文，服务器检查每句不超过20词。

录音、笔记和学习进度保存在使用者自己的浏览器。不同设备不会自动同步。JSON备份不包含音频，请单独下载录音。听写核对不是发音评分，语音示范使用设备可用的合成语音。

## 本地运行

需要Node.js 22.13或以上版本，无需安装第三方运行依赖。

```sh
npm start
```

或者：

```sh
node --env-file-if-exists=.env.local server/index.mjs
```

打开终端显示的本地地址，默认为 `http://127.0.0.1:3000`。不配置AI密钥也可以使用课程、语音和本地练习；英语教练需要自己的OpenAI API访问权限与可用额度。

`.env.example`列出支持的环境变量。真实凭证只能放在被忽略的本地环境文件或部署平台的秘密配置中，不能提交到Git。API费用由部署者的账户承担，ChatGPT订阅与API账单分开。

## 与家人一起使用

默认服务仅绑定本机回环地址。若需要局域网或远程访问，先设置`APP_PASSWORD`，再配置`HOST`。未设密码时，服务会拒绝绑定非本机地址。

浏览器登录框中的用户名可任意填写，密码使用你配置的应用密码。远程部署必须通过HTTPS反向代理或支持HTTPS的托管服务，并将`PUBLIC_ORIGIN`设为外部网址的源地址。家庭成员共享课程，各自浏览器的进度独立；本仓库不提供云端账户与自动同步。

## 添加课程

修改 `public/data.js` 中的 `window.COURSES`。每月课程包含：

- `month`：稳定月份编号；`label`：显示名称；`start`：开始日期。
- `plan`：Markdown格式的本月学习安排。
- `lessons`：20篇短文，各有稳定的`id`、`title`、`enTitle`、`words`、`text`、`translation`、`phrases`、`child`、`questions`、`challenge`。

保留已使用的月份和短文编号，否则可能影响现有学习记录。逐句训练会自动对新文本分句。本开源包不包含私人聊天中的月度生成任务；新增课程由部署者自行维护或接入自己的自动化。

## 测试

```sh

```

测试覆盖请求来源、输入校验、认证、超长句修正和API额度错误。测试使用模拟响应，不会调用付费API。实际AI生成质量与模型可用性需自行验证。

## 英语教练规则

不逐字翻译，先理解原意，再重新组织逻辑。使用日常美式表达，优先恰当的短语动词或习惯用语。每句不超过20词。纽约风格指自然直接的日常口吻，不是口音模仿；设备朗读不保证纽约口音。
